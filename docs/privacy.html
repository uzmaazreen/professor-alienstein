Privacy Policy

Professor Alienstein is used only by its owner. It does not collect, sell or share personal data from any other person.

The app asks the owner for permission to upload videos, set thumbnails and reply to comments on the owner's own YouTube channel. It stores one OAuth refresh token in the owner's private GitHub repository secrets. That token is used only to perform those actions on the owner's channel and is never shared.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
